# UART 串口音量、亮度与对比度控制使用说明

## 串口参数

- 波特率：115200
- 数据位：8
- 校验位：无
- 停止位：1
- 流控：无
- 命令结束符：回车（CR）、换行（LF）或回车换行（CRLF）均可
- 命令不区分大小写

## 硬件接线

本工程 UART 引脚定义如下：

| FPGA 信号 | 芯片管脚 | 方向 | 连接 USB-TTL |
| --- | --- | --- | --- |
| `uart_rx` | F12 | FPGA 输入 | USB-TTL 的 TXD |
| `uart_tx` | D12 | FPGA 输出 | USB-TTL 的 RXD |
| GND | 板卡 GND | 共地 | USB-TTL 的 GND |

只使用 **3.3 V TTL 电平**。不要连接传统 RS-232 正负电压，也不要把 5 V 串口电平直接接入 FPGA。TX 与 RX 必须交叉连接，并确保共地。

## 命令

| 命令 | 功能 | FPGA 回复示例 |
| --- | --- | --- |
| `PING` | 检查串口链路 | `PONG` |
| `STATUS` | 查询全部设置 | `VOL=8 BRI=100 CON=025` |
| `VOL 0`～`VOL 8` | 设置 0/8～8/8 音量 | `OK VOL=4` |
| `VOL=0`～`VOL=8` | 同上 | `OK VOL=4` |
| `VOL+` | 音量加一级，最大为 8 | `OK VOL=n` |
| `VOL-` | 音量减一级，最小为 0 | `OK VOL=n` |
| `MUTE` | 静音 | `OK VOL=0` |
| `FULL` | 恢复满音量 | `OK VOL=8` |
| `BRI 25/50/75/100` | 设置图片亮度档位 | `OK BRI=025` |
| `BRI=25/50/75/100` | 同上 | `OK BRI=100` |
| `CON 25/50/75/100` | 设置图片对比度增强档位 | `OK CON=050` |
| `CON=25/50/75/100` | 同上 | `OK CON=100` |

音量上电默认值为 8，即不衰减；亮度默认 100，对比度默认 25（自然原图档）。`VOL 4` 约为一半幅度，`VOL 0` 为静音。亮度、对比度只接受 25、50、75、100 四个档位，回复和 `STATUS` 中使用三位定宽显示（`025/050/075/100`）。无效命令回复 `ERR`，并保持原设置不变。

亮度档位是输出亮度比例：25/50/75/100 分别约为原亮度的 1/4、1/2、3/4 和原亮度。对比度以 RGB 中点 128 为中心：25 为自然原图；50、75、100 逐步压暗暗部并提亮亮部，超出范围时饱和到黑或白，不再通过抬高黑位形成灰雾。处理只作用于 TF 卡图片，左上角状态卡、底部字幕、VU、频谱和时域波形不受亮度/对比度影响，始终清晰可读。

图片通道输出固定为 RGB666 精度（每个通道低两位清零），减少部分 6-bit/FRC 显示面板在深色渐变区域进行时间抖动造成的细微闪烁；OSD 图层仍保持完整 8-bit 颜色。

屏幕左上角显示暗蓝半透明状态卡，三行分别为 `BRI`、`CON`、`VOL`，并带有不同颜色的档位进度条。串口设置先经过跨时钟同步，再统一在下一帧边界生效，所以不会出现同一帧上半部分和下半部分使用不同参数的撕裂现象。图像计算只使用移位和少量加法，不新增 DSP 或 BRAM。

音量在 PCM 数据送入 HDMI/I2S 之前调整，因此声音、左右 VU 音量条、频谱和时域波形会同步变化。增益采用移位加法实现，没有新增 DSP 或 BRAM。

为使演示时各音量档具有清晰的视觉落差，频谱和波形还会在每帧消隐期执行一次独立的显示比例映射。典型满幅频谱等级在 `VOL 8`、`VOL 4`、`VOL 2`、`VOL 0` 下分别为 96、48、24、0；`VOL 0` 时波形回到白色基准线。时域波形的二次视觉比例从 `VOL 0` 到 `VOL 8` 依次为 0、1/16、1/8、1/4、3/8、1/2、5/8、3/4、7/8，并限制在上下 32 像素内；这样最大音量的波形更饱满，各档差异清晰且不会越界。计算采用消隐期两级小流水线，不占用逐像素关键路径。参数只在视频帧边界更新，因此不会在一帧中途产生上下两种高度。

## 快速测试

1. 烧录 `lab_ex5_i2s_v1.0_contrast_flicker_fix.bit`。
2. 串口工具选择正确 COM 口并设置为 115200、8-N-1、无流控。
3. 发送 `PING` 并确认收到 `PONG`。
4. 依次发送 `BRI 50`、`CON 75`、`VOL 4`，观察左上角显示及画面/声音变化。
5. 发送 `STATUS`，确认收到类似 `VOL=4 BRI=050 CON=025` 的完整状态。
6. 发送 `BRI 100`、`CON 25`、`VOL 8` 恢复默认效果。
