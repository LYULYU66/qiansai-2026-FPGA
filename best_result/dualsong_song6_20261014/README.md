# 六首歌双板版本（2026-10-14）

## 下载文件

- `FPGA/A_AUDIO_LYRICS_6SONG.bit`：A 板，按键切歌、PCM 播放、歌词、频谱、红字实时扫描，包含五行歌头。
- `FPGA/B_HDMI_POINT_SONG_6COVER.bit`：B 板，带 HDMI 发射器，三张图缓存后跟随 A 板当前页面。
- `FPGA/A_AUDIO_PAGE_SYNC_20261017.bit`、`FPGA/B_HDMI_PAGE_SYNC_20261017.bit`：同一份最新 bit 的防混淆文件名，优先使用这两个文件。
- `TF_CARD/IMAGE1.BMP`：仪表图；`IMAGE2.BMP`：星空右半屏；`IMAGE3.BMP`：六首歌单。三张均为 640×480、24-bit BMP。
- `TF_CARD/MUSIC.PCM` 到 `MUSIC6.PCM`：16-bit little-endian、48 kHz、双声道 PCM。

使用前请清空 TF 卡根目录中旧的 `.BMP` 文件，只保留这三个 IMAGE 文件和六个 MUSIC 文件；B 板按扫描顺序将它们作为仪表、星空、歌单三个图槽。

`TF_CARD_CLEAN_20261017` 是不含旧图片归档目录的干净复制版，直接把其中 9 个文件复制到 TF 卡根目录。

## 歌曲编号

| 编号 | TF 文件 | 歌曲 |
|---:|---|---|
| 0 | MUSIC.PCM | 告白气球 |
| 1 | MUSIC2.PCM | 一路向北 |
| 2 | MUSIC3.PCM | 情歌 |
| 3 | MUSIC4.PCM | 我落泪情绪零碎 |
| 4 | MUSIC5.PCM | 搁浅 |
| 5 | MUSIC6.PCM | 枫 |

A 板 `key_song` 每次按下按 0→1→2→3→4→5→0 循环，并通过扩展音频控制包同步歌曲号；A 板页面选择同时通过同一控制包同步给 B 板。B 板上电显示 IMAGE1 仪表图，A 板切到星空页时显示 IMAGE2，A 板切到歌词/频谱页时显示 IMAGE3 歌单，页面选择与歌曲号相互独立。

歌词时间轴按每首 PCM 的立体声采样数驱动，播放切换或 EOF 会同时清零采样计数和歌词事件索引；红色扫描位置由当前采样进度计算，不依赖 UDP 到达时刻。MUSIC2.PCM 到 MUSIC6.PCM 的歌词时间轴已经按对应本地音频重新对齐；其中情歌、我落泪情绪零碎、搁浅、枫使用用户提供的简体歌词，重复段保留各自的播放时间。

标题行统一固定在第 26 行，显示为六首歌的准确歌名；红字事件按画面实际字符列计数，歌词中的空格也占位，并在下一行开始前截断当前行的最后一个字符事件，避免最后一个字漏扫或串到下一行。

A 板在首个 B 板音频状态包到达前使用本地歌头兜底显示；“分手、起风、这个季节、忍住、带刺”等用户确认字保留在字库压缩白名单中，不再被替换为空格。

当前六个事件 bank 的数量为 `[373, 358, 406, 386, 380, 446]`，总计 2349 个事件，仍满足 EG4S20 的 BRAM 资源限制。
