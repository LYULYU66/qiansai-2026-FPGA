**K1（A2）是复位键；K2（B2）是发送键。**仅在按住每块板的 K2 时，该板约每 10 ms 发送一包 8 字节数据：`DBLK`、板号、16 位递增序号、异或校验。按钮未按时不发送。首次 ARP 建表可能丢掉前几包，因此请按住 1–2 秒。

| LED | 测试含义 |
| --- | --- |
| `led[0]`（A4） | 约每秒变换一次，表示 FPGA 与测试时钟在运行 |
| `led[1]`（A3） | 本板曾向发送逻辑交付测试包，电平改变后保持至复位 |
| `led[2]`（C10） | 本板曾收到对端的有效测试包，电平改变后保持至复位 |
| `led[3]`（B12） | 本板发现无效包或序号缺口，电平改变后保持至复位 |

LED 引脚依据本板示例工程 `C:\FPGA2026\code\lesson03_td_constraints\constraints\top.adc`：A4、A3、C10、B12；K1/A2、K2/B2 引脚依据板卡原理图及去年双板工程约束。板上 LED 可能是低电平点亮，因此判据是对应灯**改变状态**，不强行要求由灭变亮。此方案不需要串口转接模块。串口源文件仅留作历史参考，不参与 A/B 工程构建。

## 上板步骤

1. 保留主板当前工作的单板 bit，不要把 A/B 测试 bit 当作正式播放器 bit。准备两块同型号板，分别供电，用网线连接板载 RJ45（若直连不建立链路，可经过千兆交换机）。
2. 用各自 JTAG 给 A 板配置 `DUAL_SMOKE_A.bit`、B 板配置 `DUAL_SMOKE_B.bit`。仅在确认哪一块是 A/B 之后再编程，避免混淆；必要时把原单板 bit 烧回主板。
3. 两板运行后，应先看到两边 `led[0]` 周期变化。按住 A 板 **K2** 约 1–2 秒：A 板 `led[1]` 应改变状态，B 板 `led[2]` 也应改变状态。松开后，再按住 B 板 **K2**：B 板 `led[1]` 应改变状态，A 板 `led[2]` 也应改变状态。K1 只用于复位。**只看到按键板自身的灯变化，不能证明网口收发成功。**
4. 注意观察网口链路灯。若本板 `led[1]` 改变、对板 `led[2]` 不变，先核对 A/B bit、网线和网口链路，再排查 UDP／RGMII；若 `led[0]` 不周期变化，先查供电、配置与复位。`led[3]` 改变说明收到无效包或存在序号缺口，需要进一步排查。

本阶段**没有**将 TF、图像、PCM、歌词或频谱迁往副板。只有双向心跳收发的真实上板结果合格后，下一阶段才定义媒体包格式、缓存切换和主板资源回收。
