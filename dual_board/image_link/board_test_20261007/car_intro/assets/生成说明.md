# 仪表页汽车出场素材

使用 imagegen 技能及内置 image_gen 生成单张透明汽车素材，原图保留在 car_master.png。没有生成视频或多帧车图，也未修改 TF 中的图片。pack_sprite.py 仅做裁切透明留白、等比例缩小、色表量化和 FPGA ROM 格式打包，不重新绘制汽车。

最终 256×96，4bit 索引，0 为透明，15 个不透明颜色，24576 像素；每 4 像素装入一个 16bit 字，3 个原生 BRAM32K。car_indexed256x96.png 用于审阅实际硬件色表效果，不等同于原始高清母版。为节约资源保留有限色表和二值透明，没有采用全 RGB888 多帧视频。

Photorealistic automotive geometry, clean metallic silver and cool white body, dark graphite windows and grille, sharp crisp readable silhouette, strong but restrained blue-violet rim lighting, bright slim white-cyan LED headlights already on. Beautiful and cool like a premium car dashboard boot animation. Lighting from above and side, highlights clear enough to remain attractive after 16-colour quantization and downsampling. Actual transparent background, no background scene, no black rectangle, no floor, no drop shadow, no reflected duplicate car, no ground halo (drawn later by FPGA), no particles, no laser beams, no dashboard, no gauges. No text, no logos, no license plate lettering, no watermark. Output only the one isolated car, not a sprite sheet, not multiple angles.
