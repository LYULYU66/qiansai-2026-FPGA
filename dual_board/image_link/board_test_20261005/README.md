# 双板媒体链路：临时 SRAM 上板联调

本包是**尚未时序闭合的工程测试版，不是稳定发布版**。用于首次验证真实 TF→以太网→SDRAM/HDMI 的图片和声音链路；编译时没有删减现有功能。不能凭仿真通过、成功生成 bit 或原诊断灯正常，宣称正式播放器实板通过。无需等所有资源优化结束才开展这轮可回退的硬件测试。

## 两个文件与接法

| 角色 | 下载文件 | 外接设备 |
| --- | --- | --- |
| A 主板：最终显示、HDMI 声音、本地危险开关 | `MEDIA_SRAM_TEST_A_MAIN_20261005.bit` | 原先使用的 HDMI 输出口连接显示器；危险拨码开关保留在 A |
| B 副板：TF 读取、音频分析、首页图层生成、电脑串口 | `MEDIA_SRAM_TEST_B_TF_20261005.bit` | **唯一的 TF 卡插在 B**；需要串口测试时电脑接 B |

网线直接连接两板此前灯光测试通过的 **PHY1 网口**，不要接另一未配置网口。固定对端 IPv4/UDP，不需电脑交换媒体，也不支持 Ping。两板分别供电；无需额外连接 GPIO 串口线。

保留原 TF 卡内的四张合格 BMP 和 `MUSIC.PCM`，不重新格式化、不更换媒体文件。PCM 仍为 48 kHz、16-bit、立体声、小端裸 PCM，顺序 L低、L高、R低、R高。B 需要先预载现有图片再启动音乐，首次等待期间无声不能单独判定为故障；本版本不播放音阶作为回退音。

## 下载：只使用 PROGRAM_SRAM

1. 标记 A、B，避免两块相同板混淆。为避免选错下载器，先只连接 A 的下载 USB，把 **A_MAIN** bit 下载到 A。
2. 切换到 B 的下载 USB，把 **B_TF** bit 下载到 B。两板必须使用本包配对文件，不能混配灯光诊断、旧 IMGF 图案或单板 bit。
3. 本轮选择 **PROGRAM_SRAM**，不选 PROGRAM_FLASH，不做擦除操作。它不改写原来的启动 Flash，掉电会丢失临时程序。
4. B 插 TF，A 接 HDMI，两板连网线；A 的 SW1–SW4 先置 0。两板下载完后分别按一下 **K1 复位**。

K1 是 A2 管脚的复位键，不是切图键。本包 A 的 K2（B2）手动下一页，K3（C1）开启/关闭自动轮播；B 无需按发送键，会在会话建立后自动读卡与发包。

## 分层验收，先静止画面与音频

1. **先不要开自动轮播或危险开关。** 默认停在第一页；观察 A 数码管能否从 0 到 1，第一张图片是否完整显示、保持稳定。它只在完整接收、CRC 检查及 SDRAM 写入完成后显示该帧。
2. 等图片预载结束，听 HDMI 是否开始播放卡中音乐，记录是否卡顿/断音。这是本次最重要的“图片＋TF 音频”验收，不需要先看所有效果。
3. 按 A 的 K2，依次观察 1→2→3→4→1。第二页检查频谱、波形、歌词；第三页检查星点/时间；第四页检查方向预警背景。图片切换时音乐应连续。
4. 再按 K3 测自动轮播。四个危险开关分别为 SW1 后、SW2 前、SW3 左、SW4 右；单独触发后应直接到第四页、显示相应警示，音乐减弱并叠加报警声；解除后恢复普通状态。
5. 有电脑串口时再测 B 的 `VOL 4` 等已有文本命令，115200、8N1、带回车换行。串口收到 OK 只代表 B 接受命令，需同时观察 A 的参数和声音是否变化。
6. 在第一轮图片/声音通过之后，再做 B 单独复位、A 单独复位和短暂拔插网线，核对会话重建及播放恢复。不把重连与首次启动混在一次测试里。

确认图片和声音正常以后，其他步骤可以分次进行。不要仅根据网口灯或 B 的第三盏灯认定整套媒体系统通过。

### B 指示灯的含义

- LED1（`led[0]`）：UDP 媒体域心跳；会话未建立、媒体域仍复位时可能不跳。
- LED2（`led[1]`）：SD 状态码非零，**不等于专门的错误灯**。
- LED3（`led[2]`）：B 的媒体包装器已得到可显示图片；不能替代 A 的屏幕/数码管验收。
- LED4（`led[3]`）：图片跨域 FIFO 溢出标志。

以灯状态的变化判断，不假设高电平一定亮。

**两板均未时序闭合，所以本包可能出现启动失败、花屏、卡音或重连异常。** A 不仅存在原 SDRAM 特殊 IO 负路径，还存在真实 UDP 控制路径负裕量；B 也有 SD/UDP 同域路径和跨域复位/元数据负裕量。不能把这些全部当成假路径忽略。A 的 TD 报告还保留与 R3 相同的内部 SDRAM 位置及 `ext_mem_clk_sft` 局部布线警告；未改约束去隐藏它们。本轮未完成外部 PHY、TF、DDC 的规格级 IO 延迟审计。

首次测试如果失败，记录“数码管、屏幕、声音、B 四灯、经过多久发生”，先恢复原程序，不反复固化这个版本。串口/歌词/图层同步成功也不能替代时序签核或长时间硬件验证。

## 仿真与可追溯性

本包 A 逻辑等同 R3，B 等同 R5 加本轮确认包资格寄存级。无 PLL/引脚/IP/FIFO 容量/媒体协议更改，没有增加整域 false-path。B 的 AAK2/AAK3 输出与原版逐拍一致，资格检查提前到最后一个 CRC 字节，有效确认脉冲仍在原来的时钟周期。

- 上一轮 R5 的完整 40 项回归和图片发送 6 配置对照保留，**并非声称本轮又重跑了全部 40 项**。
- 本轮新的确认包逐拍测试：AAK2、AAK3 各 1200 包，合计 240 个合法包、2160 个拒收包；CRC、错误长度、保留控制位、音量范围、间断、超长和复位通过。
- 本轮实际 B 应用顶层：640 PCM 字、长度冻结、串口、残包排空、会话重建、三次图像中止恢复通过。该测试替换已解码 SD 输出和网络引脚传输，不是实卡/PHY 仿真。
- 本轮完整图像源：614400 RGB＋索引字、两种存储方向、100/125 MHz 跨域、回压通过。
- 本轮音频专项共七项：AAK3 状态、视觉包守卫、25/125 MHz 远程分析、实际 48 kHz 播放同步、PCM 守卫、媒体中止、原生 FIFO/重传/歌曲循环。最终日志完整性和 PASS 标记由打包脚本核验。

资源/时序、源码与 bit 的 SHA256、上述日志及旧版本保护检查见本目录 `manifest.json`，本轮代码说明见上一层 `phase14_receipt_pipeline_notes_20261005.md`。本包尚未上板，验收结果栏保留为空。

## 回退

仅做 SRAM 下载时，掉电重启会恢复各自原有 Flash 内容；原 Flash 不保证此前固化的是什么版本。需要已知文件时，A 可重新 SRAM 下载原单板 `best_result/lab_ex5_i2s_v1.0_logic_round3_20261003.bit`，并把 TF 卡放回 A；此时它是单板播放，不再与 B 联动。两板网口诊断需要另行下载 `dual_board/fixed_udp_hw/prj/board_a/FIXED_UDP_HW_A_20261005.bit` 和对应 B 文件。这些文件均保留、没有被本轮覆盖。
