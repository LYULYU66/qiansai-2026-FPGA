# 正式双板播放器：低风险流水化与复位隔离

本轮是正式播放器的**硬件候选验证**，不是已经通过实板的播放器版本。此前用户报告“灯没有问题”对应独立固定 UDP 诊断；不能把它作为 TF/HDMI/SDRAM/音频播放器已通过的证据。单板、已验证诊断 bit、第十阶段正式源码和原始仿真断言均保持不变。

## 实现范围

只在独立硬件覆盖文件中进行以下修改，旧工程仍可复现：

1. A 的播放样本计数：两拍 Gray 同步之后，增加一拍二进制解码寄存。仍是实际播放头，最多晚一个 UDP 时钟（8 ns），不会使用将来的样本数。
2. B 的音频历史队列：Gray 解码、积压量相减、容量判断分开流水。保持原 1024 样本历史 RAM 和最大 896 样本占用，满速输入的两拍反应余量由阈值 894 预留；不缩减 32 位计数，不改变回绕、音量、歌词、重传或断流恢复。
3. B 的首页索引 ROM：读出后的长度加法另加一级，每个压缩 run 多等待一个 UDP 时钟。图标、字体、颜色、BMP 上下方向和像素接受规则完全保留，不增加 ROM/BRAM。
4. A 的帧缓存状态机：复位异步置位、在内存时钟下两拍同步释放。新增复位只接内存域状态，UDP 侧 FIFO 空间判断保留原表达式，避免把内存复位寄存器重新串入发送流控。

没有改变 PLL、引脚、HDMI/SDRAM/MAC 加密核、FIFO 深度、协议格式或相关时钟约束；没有把相关 25/100/125 MHz 时钟整体切成异步来消除违例。对比度/亮度、预警、转场、歌词、首页、星点和时钟功能未删除。

以上是 **routed** 数字，不覆盖第十阶段冻结的 gate 综合数字。资源容量可放下，但时序仍不合格，STA 覆盖也不代表外部 IO 延迟已完全正确约束。

A 初始版本和第一轮流水版未布通。第二轮局部复位版本布通，但把局部复位接到整个帧读写模块后，新增内存域到 UDP 流控长路径，因此未采用。第三轮把复位限制到真正的内存状态，种子 7 出现另一处复位补偿线碰撞；保存失败日志后，同一 RTL 用种子 3 布通。**换种子只处理局部布线合法性，不是时序闭合措施。**

B 原 −4.069 ns 的音频 Gray 解码/减法/ready 长链，以及 −3.127 ns 的首页 ROM 长链已不再是当前最差路径。仍不能仅凭这两条路径消失说整个系统提速或降低功耗。

## 仿真证据

音频流水版完整 40 项 ModelSim 回归已经重跑通过，零仿真错误、106 条警告消息（可选端口/原生 FIFO 等），按本次实际日志计数；日志 `sim/hw_20261005/modelsim_all.log`。原始测试源码和断言哈希与第十阶段相同，没有放宽检查。

新增满速输入压力测试也通过：125 MHz 连续输入、RAM 回绕、中途复位、4201 个已分析样本逐个核对，最大历史占用准确保持 896。日志 `sim/hw_20261005/modelsim_guard.log`。

后续内存/首页改动的 7 项专项回归已经通过：40 种复位相位与窄脉冲、真实帧读状态机、原生 FIFO 和 UDP 空间判断、首页全页字模/像素比较、双存储方向与发送回压，零错误、31 条原生 FIFO/既有可选端口或宽度警告消息。日志 `sim/hw_round3_20261005/modelsim_round3.log`，连同前一项满速测试，本轮共完成 40 项完整回归和 8 项专项检查；完整证据见 `phase11_pipeline_validation_20261005.json`。不能把前一轮的 40 项结果说成在最新完整顶层上重新跑了 40 项。首页源测试替换的是已解码的 SD 输出，不等于真实 TF/FAT 整链测试。

全回归与专项回归最初的包装脚本误要求日志末尾必须回显 `quit -code 0`，而 Starter 的嵌套 DO 正常结束不会回显该行（旧完整日志也是如此）。实际全部测试和仿真器退出成功；已修正日志完整性判据，再对完整原日志校验，没有修改日志、测试断言或重用旧版结果。

## 未完成边界与下一轮

本轮没有生成或下载新的播放器 bit。优先继续以下实际端点，而不是放宽时钟或堆缓存：

1. B 的源数据/复位跨 100/125/25/50 MHz：分别同步释放复位，音频文件长度在 stream 握手后锁存成完整 UDP 域元数据；稳定元数据路径与第一拍 Gray 同步路径分别审计，不能整域 false-path。
2. B 的 125 MHz 图片发送 RAM 到调度器/UDP，以及 UDP 接收 RAM 到确认解析器：局部数据流水需要保持完整包连续性、尾 CRC 和异常包排空行为。
3. A 的远程可视化进度判断，以及 50 MHz 监督复位到 UDP 流控：按具体端点继续缩短，保持“按实际播放头同步、禁止未来进度发布”。
4. A 的 SDRAM 原有 primitive IO 路径约 −5.699 ns，另行审计 IP/器件时序建模；不擅改加密代码或 PLL 相位。小幅保持违例也不能忽略。
