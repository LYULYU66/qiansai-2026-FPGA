# 回退到原来的频谱显示版本

本目录恢复使用传统的第二页显示：16 段频谱柱、连续时域波形、左右音量表、歌词和原歌曲卡片。Sonic Topography 地形显示不参与本版本。

## 烧录文件

- A 板：`MEDIA_A_STARS_OPT_20261007.bit`
- B 板：`MEDIA_B_STARS_OPT_20261007.bit`

A、B 必须成对烧录，选择 `PROGRAM_SRAM`，不要把本目录的 A bit 与 Sonic Topography 目录的 B bit 混用。

## 操作

1. 先给 B 板烧录 B bit，再给 A 板烧录 A bit。
2. 两板接好网线后，先复位 B，再复位 A。
3. TF 卡仍插在 B 板，保留原来的 BMP 和 PCM 文件。
4. A 板第二页恢复原来的频谱、波形、歌词与音乐卡片；首页、预警页、亮度/对比度、音量、双屏星点和 B 板仪表功能沿用原版本。

Sonic Topography 候选仍保留在 `board_test_20261010/sonic_topography`，没有删除或覆盖。
