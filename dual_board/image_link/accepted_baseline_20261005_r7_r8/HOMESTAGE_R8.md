# B 副板图标像素暂存候选 R8

现象：用户报告 A R7 更新后图片能显示，但首页应用图标处仍有局部花屏。具体是静态坏行还是随显示变化尚待用户确认。本版为针对已报告图标推进路径负裕量的候选，不是已证实解决板上花屏的稳定版。

保持 A 主板 MEDIA_SRAM_TEST_A_IMAGEFIX_R7_20261005.bit 不变，仅更新 B 为 MEDIA_SRAM_TEST_B_HOMESTAGE_R8_20261005.bit。旧 B 的 MEDIA_SRAM_TEST_B_TF_20261005.bit 保留。TF 卡内容不用改，不改网口协议、SDRAM 控制器、FIFO 深度、PLL、约束或音频通路。

原 B 的发送端 ready 信号组合传到首页索引 consume、行坐标和运行地址寄存器使能；布局布线报告该 UDP 域关键路径为 -1.627 ns。R8 将 RGB、图标索引和首像素标志一起暂存为一个像素，首页只在暂存接收时推进，发送端则消费已经稳定的暂存数据；等待发送及重传期间不会更换暂存内容。新增单像素级寄存器，不增加 RAM。

布局布线（seed 1）：B LUT 11847（60.44%），寄存器 7770，BRAM9K/BRAM32K/DSP/PLL 为 28/9/3/3。旧 B 为 11726 LUT（59.83%）、7763 寄存器，硬块不变。物理优化后的资源差值不等于源码新增位数。UDP 同域最差 -1.627→-0.525 ns，关键路径转到音频包调度器 CRC；全局建立 -3.251→-3.487 ns，保持 -1.540 ns 未改善，仍未时序闭合，不应描述为整体时序闭合或全面改善。

读侧排查：A R7 原生 FIFO + video_delay + 转场 + 亮度 LUT + 调色板，用 SDRAM 应用接口模型加入刷新停顿和并发 307200 字预载；完整首页 307200 个 RGB/tag 与调色板像素检查通过，无空读。该行为仿真不能覆盖物理 SDRAM、HDMI 或网口电气时序，也不能证明板上花屏根因。

R8 新跑验证：实际 B 顶层 FIFO/调度器/计算边界，640 个 PCM 字、串口、会话重连、3 次图像中止通过；实际 B 图像源 100/125 MHz CDC、图标解码器、发送器与接收器，两个页面共 614400 个 RGB/tag 在两种存储方向和背压下通过；另一次完整 614400 字压力测试，丢弃每页首包及末包应答（共 4 次），重传后无重复像素，暂存 RGB/tag/首像素标志在等待和重传期间稳定。R6/R5 全套回归未在本轮重跑；本轮四次专项行为测试不能替代板上检验。

下载方式：PROGRAM_SRAM，暂不固化。只烧 B，A 不用重烧，复位两板重新加载。观察应用图标是否恢复、等待 30 秒后是否稳定；切到第 2/3/4 页再回来，并检查音频、字幕、串口和危险开关。如果变差，B 烧回旧 bit，A 仍留 R7。
