# A 主板图片启动修复 R7

仅更新 A 主板，B 副板仍使用 MEDIA_SRAM_TEST_B_TF_20261005.bit。旧版文件不覆盖。

用户报告旧双板测试版音频正常，但 A 数码管一直为 0、HDMI 黑屏。本次 ModelSim 使用实际图片 SDRAM 接收端、原生异步 FIFO 和帧写控制器，复现了首像素在 FIFO 复位窗口丢失：1024 个输入仅完成 768 个 SDRAM 写入，无法提交缓存。

修改仅限 frame_read_write：FIFO 复位及同步释放期间禁止接收像素，增加 3 个释放寄存器；FIFO 计数输入显式补零，消除仿真中宽度不匹配导致的悬空位。未修改 B、音频通路、PLL、HDMI 核、SDRAM 控制器、FIFO 容量、网络协议或约束。

专项验证：旧版 3 种相位均复现；修复版 5 种相位各连续 3 帧逐数据/地址核对通过；完整 640×480 的 307200 个 RGB/tag 字全部核对并提交缓存。这里模拟的是 SDRAM 应用端写入接口，不是物理 SDRAM 电气模型，也不是板上验证。

下载使用 PROGRAM_SRAM，不固化。TF 卡在 B，HDMI 接 A，网线连接两板。下载后复位两板，首先观察 A 数码管是否从 0 变 1、图片是否出现且音频继续播放，再检查 K2 切图、K3 轮播和四个危险开关。时序是否闭合以新布局布线报告为准，负裕量未解决时仍属实验版。

新布局布线结果：LUT 14483（73.89%），寄存器 9240，BRAM9K/BRAM32K/DSP/PLL 为 50/7/3/4。相对原 A 测试版 LUT 增加 203，硬块不变；虽源码新增逻辑很少，物理优化后的总 LUT 不保证只增加三个寄存器。全局建立最差 -5.699 ns，保持最差 -0.052 ns，仍未时序闭合。仅可临时上板验证，不能据行为仿真宣称物理时序稳定。
