# 车机底栏图标素材

`source.png` 为用户提供的整条截图；`raw/` 为按原顺序逐个裁切的图标。
`clean/` 含 13 个重绘后的透明 PNG：`*_96.png` 是 96×96 几何重绘素材，
`*_native.png` 是实际用于 FPGA 的 24×24、2-bit 抗锯齿版本。
另有共享的 36×16 “21.0”文字素材。

截图原本仅 34 像素高，不能从中恢复真正的高清细节；清晰版是根据原轮廓重新绘制，
不是简单放大，也不是车厂原始图标。`toolbar_native.png` 是最终 640×40 的底栏。

顺序：主页、车辆、多窗口、21.0、左座椅、出风方向、车内循环、风扇、前除雾、
后除雾、右座椅、21.0、音量、文件/收纳、屏幕。

这些图标和温度均是显示示例，目前没有连接车辆空调、温度传感器或控制执行器。
除中央风扇使用青绿色强调外，其余采用统一深灰线条。底栏为白色直角、40 像素高。

离线生成脚本：`sim/generate_bottom_nav_icons.py`。它向标准输出输出 apply_patch
补丁，不直接写 HDL；在修改源代码时必须用 apply_patch 应用该补丁。
13 个图标和一个共享温度块共占 1008 个 16-bit 字，映射到 2 个 BRAM9K。
